Вебпроєкт: Лабораторна робота (lab1-klochkova)

Цей репозиторій містить багатосторінковий адаптивний вебсайт, 
розроблений за допомогою сучасних стандартів HTML5, CSS3 (Grid, Flexbox, змінні `:root`) та власної дизайн-системи.

1. Призначення сайту й тема варіанта
- Призначення: Інформаційний вебпортал для демонстрації структурованого контенту, розкладу занять,
ресурсів, галереї та форм зворотного зв'язку.
- Тема варіанта: Спеціалізований навчально-інформаційний ресурс (варіант студентки Клочкової).

2. Спосіб запуску
Для локального запуску та перевірки сайту:
1. Завантажте або клонуйте репозиторій на свій комп'ютер.
2. Відкрийте папку `lab1-klochkova` у редакторі коду VS Code.
3. Для коректного завантаження відносних шляхів, зображень і шрифтів запустіть проєкт
через розширення Live Server (натисніть правою кнопкою миші на `index.html` «Open with Live Server»).

├── css/
│   ├── fonts/                # Вебшрифти (Inter WOFF2)
│   ├── print.css             # Стилі для друку
│   └── style.css             # Головний файл стилів із CSS-змінними
├── docs/                     # Документація до проєкту
├── img/                      # Графічні матеріали, іконки та фото (photo-1...6)
├── other/
├── pages/
│   └── resources.html        # Сторінка ресурсів
├── 404.html                  # Сторінка помилки 404
├── about.html                # Сторінка "Про нас"
├── application.html          # Сторінка подачі заявки
├── comparison.html           # Сторінка порівняння
├── contacts.html             # Сторінка контактів
├── gallery.html              # Сторінка галереї
├── index.html                # Головна сторінка сайту
├── privacy.html              # Політика конфіденційності
├── robots.txt                # Інструкції для пошукових роботів
├── sitemap.xml               # XML-карпа сайту
└── style.html (styleguide.html) # Довідник дизайн-системи (Style Guide)

Шрифти: Шрифт Inter (набори inter-regular, inter-bold, 
inter-cyrillic) — розповсюджується за ліцензією SIL Open Font License.
Зображення: Фотографії та іконки (photo-1 — photo-6, SVG-іконки) 
використані з відкритих демонстраційних джерел для навчальних цілей.

Проєкт є статичним фронтенд-рішенням, тому інтерактивні елементи форм і зв'язку виконують демонстраційну роль 
без підключення до реального серверного бекенду.

Адаптивність інтерфейсу оптимізована для сучасних мобільних пристроїв, планшетів і десктопних моніторів.
