Довідник стилів (Style Guide)

Простий довідник для перевірки основних елементів вашого проєкту.

Основні кольори

--color-primary
--color-accent
--color-primary-soft

Кнопки (.btn)

<button class="btn btn--primary">Головна</button>

Поля введення

<input type="text" class="form__input" placeholder="Текст...">

Картка (.card)

Заголовок

Приклад тексту всередині картки.

Дія 
<div class="card">
    <h4>Заголовок</h4>
    <p>Текст картки.</p>
    <a href="#" class="btn btn--primary">Дія</a>
</div>

Основний текст і параграфи

Це звичайний параграф тексту (p), який використовує базовий розмір шрифту та міжрядковий інтервал із вашого файлу стилів.

Жирний текст та звичайний текст усередині абзацу.

<p>Це звичайний параграф тексту.</p>

Посилання та специфічні індикатори

Звичайне посилання у тексті: посилання на сторінку.

Посилання на зовнішній ресурс (автоматично додає стрілочку через CSS): Зовнішній сайт.

Посилання на PDF-файл (автоматично додає позначку): Звіт за рік.

<a href="#">посилання на сторінку</a>
<a href="https://example.com">Зовнішній сайт</a>
<a href="document.pdf">Звіт за рік</a>
